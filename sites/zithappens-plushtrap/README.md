# Zit Happens official brand page

This directory is the durable source for the independent Cloudflare Pages project
zithappens-plushtrap and its production custom domain:
https://zithappens.plushtrap.com/

The old zithappens.co domain has expired and is NOT an operational dependency.
The page describes the genuine Zit Happens Killa Bunny collaboration with Plushtrap.

Cloudflare Pages serves files from this directory root, not the SMAT portfolio root.
Keep the public page at sites/zithappens-plushtrap/index.html and deploy
only that directory using the existing authorized Wrangler session.

Deploy command:
    wrangler pages deploy sites/zithappens-plushtrap --project-name=zithappens-plushtrap --branch=main

Check the canonical domain, live product link, TLS, robots.txt, sitemap.xml,
and business identity before making any Google Business Profile website edit.
Custom-domain DNS is managed separately in the Cloudflare account.
